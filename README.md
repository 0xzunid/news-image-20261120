News in one image — 20 November 2026 front page. Sums up 20 November's world news in a single 1024×1024 newspaper front page, drawn with Pillow: the ICJ ruling that Myanmar committed genocide against the Rohingya, the first Trump–Xi–Putin three-way summit in Shenzhen, Anthropic's record $81.3bn IPO, Iran's escalating Hormuz tanker attacks, Ukraine hitting the Crimean Bridge a third time in four days, and Cyclone Akvan's landfall — plus the day's smaller stories in one "Also today" strip.

## Run it

```sh
python3 main.py
```

That copies `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output`). The image itself is generated by `news-image-gen-20261120.py` (kept out of this repo) with Pillow and DejaVu fonts — crisp baked-in headline text, no AI-image text garbling.
